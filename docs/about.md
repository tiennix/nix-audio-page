# About

NIX Audio is made by **tiennix**, an independent Unity developer. It grew out of the audio module of my own
game framework, used in my projects, and was rebuilt as a standalone package for the Unity Asset Store.

- Email: [tientv.0702@gmail.com](mailto:tientv.0702@gmail.com)
- GitHub: [tiennix](https://github.com/tiennix)

## How NIX Audio was made

The runtime architecture comes from my own framework module. The editor windows, the demo audio clips and
parts of the packaging work were produced with the help of Claude (Anthropic), then reviewed, revised and
tested by me. The package ships with EditMode tests and is verified in clean Unity 2022.3 and Unity 6
projects.
