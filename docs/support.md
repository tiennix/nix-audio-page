# Support

- **Email:** [tientv.0702@gmail.com](mailto:tientv.0702@gmail.com).
- **Bug reports and feature requests:** [GitHub Issues](https://github.com/tiennix/nix-audio-page/issues/new/choose).

When reporting a problem, please include:

1. Unity version and render pipeline (Built-in, URP, HDRP).
2. NIX Audio version (see `NixAudio/CHANGELOG.md`).
3. The full Console message, with its stack trace.
4. Steps to reproduce, or a small sample project.

Before writing, the [FAQ](faq.md) and [Limitations](docs/limitations.md) may already answer it.
